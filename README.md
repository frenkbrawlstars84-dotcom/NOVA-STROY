# NOVA STROY

Одностраничный сайт вымышленной компании по ремонту квартир в Минске. Портфолио веб-разработчика; интерьеры, услуги и ставки демонстрационные. Статистика, отзывы, реальные адреса и телефоны не используются.

## Запуск на Windows

1. Установите Node.js 24 LTS с [nodejs.org](https://nodejs.org/) (включая npm).
2. Откройте PowerShell в папке проекта.
3. Выполните:

```powershell
npm install
npm run dev
```

Откройте адрес, который покажет Vite. Для остановки нажмите Ctrl+C.

## Проверки и сборка

```powershell
npm test
npm run build
npm run preview
```

`npm test` выполняет четыре проверки расчёта: базовая ставка, коэффициент вторичного жилья и дополнительные работы, изменение площади и типа ремонта, ограничения площади. `npm run build` проверяет TypeScript и собирает проект в `dist/`. Для воспроизводимой установки по lock-файлу используйте `npm ci`.

## Возможности

- React 19, TypeScript, Vite, Tailwind CSS 4, Motion и Lucide React.
- Адаптивные секции, фиксированная навигация и мобильное меню.
- Шесть услуг и шесть вымышленных проектов; фильтры и галерея референсов.
- Калькулятор с автоматическим диапазоном BYN и переносом параметров в форму.
- Проверка имени, белорусского номера +375 и площади. Номер в примере формата не является контактом компании.
- Демо-подтверждение: формы **не отправляют и не сохраняют** данные. Сервер, почта и Telegram не подключены.
- Клавиатурная навигация, Escape и удержание фокуса в модальных окнах, видимый фокус, prefers-reduced-motion.

## Расчёт

Ставки, коэффициенты, пределы площади и диапазон вынесены в `src/pricing.ts`. База: площадь × (ставка вида ремонта × коэффициент жилья + сумма выбранных дополнительных ставок за м²). Диапазон — 90–120% базы с округлением до 100 BYN. Материалы не включены; дополнительные позиции условно прибавляются к базе. Это демонстрационная модель, не прайс и не коммерческое предложение.

## Фотографии

Фотографии загружаются с `images.unsplash.com`, с ограничением ширины и автоматическим выбором формата. Использованы публичные изображения Unsplash по [лицензии Unsplash](https://unsplash.com/license), как референсы, а не выполненные заказы. Идентификаторы находятся в `src/App.tsx`. Для работы нужна доступность этого домена; в облачной среде он добавлен в черновик разрешённых доменов. Сохранение черновика само по себе не применяет сетевые настройки. Перед коммерческой публикацией проверьте актуальные условия лицензирования выбранных изображений и права на узнаваемые объекты.

## Структура

- `src/App.tsx` — секции, содержимое, формы и взаимодействия.
- `src/pricing.ts` — редактируемая конфигурация и расчёт.
- `src/pricing.test.ts` — проверки расчёта.
- `src/style.css` — дизайн, адаптивные состояния и Tailwind.
- `index.html` — SEO и Open Graph.

Для реального использования отдельно подключите обработчик заявок и согласуйте обработку персональных данных. Замените демонстрационные тексты, контакты, ставки и проекты подтверждёнными данными компании.
